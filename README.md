## How to Use

### Local Development
1. Open `index.html` in any modern browser
2. No server required - works with file:// protocol
3. For best experience, use Chrome, Firefox, or Edge

### Deployment
1. Upload all files to your web server
2. Ensure all three files are in the same directory
3. Access via `https://yourdomain.com/`

### Customization
- **Change Colors**: Edit CSS variables at the top of `styles.css`
- **Update Content**: Modify text in `index.html`
- **Add Projects**: Duplicate project card structure
- **Add Skills**: Add new skill cards with appropriate data attributes
- **Change Theme**: Default is dark mode, toggle with button
